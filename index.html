Decisions for the Code 99 / RRT Committee

1. Add a "Physician Documentation" section to the policy DECISION
The 09/2026 policy names only the Resuscitation Record and the RRT Flow Sheet. Proposed: "The Team Leader completes the Code 99 Note – Physician in the EHR, and the responding resident completes the RRT Note – Physician, before the end of the shift (or within 24 hours). Notes written by residents are co-signed by the hospitalist or attending per GME policy."

2. Attending and family notification on two records DECISION
Both the Resuscitation Record and this note record notification. Recommended: the nurse records that it happened and when; the physician records who was told and what. Accept the overlap until iView replaces the paper record, then drop it from the nursing build.

3. Nursing form alignment DECISION
Update the RRT Flow Sheet activation criteria to the policy's 12 criteria (R1 already uses them). Add "Mechanical (LUCAS)" compressions to the Resuscitation Record / iView.

4. Immediate Post Cardiac Arrest Assessment box DECISION
The physician note now owns it (C4, C5, S5). Leave the Resuscitation Record box with "see physician note", or remove it in the iView version.

5. Build question for Medsys DECISION
PowerForm results land in Form Browser. Confirm whether these PowerForms should feed a "Code 99 Note" / "RRT Note" document type (Dynamic Documentation) so they file with physician Progress Notes and support co-signature routing. The field list does not change.

What Changed from the Proposed Templates (11/9/26)

Kept: two separate physician forms (Code 99 and RRT), the committee's section order, structured choices with narrative for reasoning.

Removed (recorded elsewhere or redundant):

  • Separate date and time fields → PowerForm "Performed on" is the event time; signing records documentation time.
  • Physician arrival, Code 99 activation and conclusion times, ROSC time → Resuscitation Record / RRT Flow Sheet.
  • RRT initial and repeat vital signs, post-ROSC BP/HR/SpO₂/rhythm → iView / RRT Flow Sheet.
  • "On arrival: unresponsive / pulseless / apneic" and initial rhythm → C1 plus the Recording Nurse.
  • Separate "CPR performed" field → CPR is in the C2 checklist.
  • Printed "per current ACLS/PALS protocol" sentence → no automatic attestations.
  • Mental status and airway pick lists, four exam boxes, four intervention groups, separate differential / response / monitoring boxes → one assessment, one impression, one plan.
  • Supervising attending signature lines → native co-signature routing.
  • Debrief items → Debriefing for Resuscitation Event form.

Added or changed:

  • S2 author role (policy roles; addresses role confusion).
  • S4 code status checked against the active order — never pre-selected.
  • C1 uses the policy's Code 99 definition; R1 uses the policy's 12 RRT criteria.
  • C2 includes mechanical CPR (LUCAS); airway and access items flag a separate procedure note.
  • C4/C5 immediate post-cardiac arrest assessment as two pick lists.
  • C6 reason resuscitation stopped uses the Resuscitation Record values; C7 time of death pronounced.
  • R5 escalation rule: the RRT note ends at escalation and points to the Code 99 note.
